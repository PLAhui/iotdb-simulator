# 界面与交互

前端是**单个 `index.html`**：样式、结构、逻辑都在一个文件里，不用构建工具。改完直接刷新浏览器即可，没有编译步骤。

## 1. 信息架构

```
顶栏（60px，sticky）      品牌 · 版本 · 当前连接指示灯
页头摘要（54px）          标题 + 场站前缀 / 可写设备 / 时间序列 / 采样周期
页签（51px）              数据库管理 · 路径与结构 · 造数规则 · 生成与预览
内容区                    固定高度，面板内部滚动，整页不滚动
底部控制台（238px）        进度条 + 分级日志，可折叠为 42px 标题条
```

四个页签的职责：

| 页签 | 内容 |
|---|---|
| 数据库管理 | 连接列表（增删 / 切换 / 连通指示灯）+ 连接表单 + 连接诊断四格 |
| 路径与结构 | 路径前缀工具条 + 通栏层级表单 + 可折叠实时路径预览 |
| 造数规则 | 规则表（分类 / 值域 / 单位 / 模型 / 匹配式 / 周期）+ 变化模型图例 |
| 生成与预览 | 规模估算四格 + 分层明细 + 写入设置 + 生成 / 停止 |

## 2. 固定高度工作台

整页不滚动的核心算式：

```css
html, body { height: 100%; overflow: hidden; }

.app {
  max-width: 1240px;
  padding: 0 28px;
  height: calc(100vh - 60px - var(--dockh, 238px));  /* 顶栏 + 控制台 */
  display: flex;
  flex-direction: column;
  overflow: hidden;
}
body.dock-folded { --dockh: 42px; }   /* 控制台折叠时把高度还给内容 */

.panel.active {
  display: flex; flex-direction: column; gap: 11px;
  flex: 1; min-height: 0; overflow-y: auto;
}
```

控制台展开 / 折叠时，`--dockh` 变化会让内容区自动伸缩，不需要 JS 计算高度。

**亚像素修正**：`flex` 布局下常有 `scrollHeight - clientHeight === 1px` 的差值，会闪出一条滚动条。`fitPanel()` 在切换页签与每次刷新后测量：

- 溢出 ≤ 2px → 加 `.tight`（`overflow-y: hidden`），当作已放下；
- 溢出 > 2px → 加 `.scrollable`，底部加渐隐遮罩提示"下面还有"。

## 3. 层级表单（路径页的核心组件）

```
层级            编码范围                        设备数    已配测点
[c] 舱     [ c101-c102                  ]        4 台     13 点 soh·singemax…   ⌄
[cu] 簇    [ c001-c074                  ]      296 台     28 点 totv·toti…      ⌄
[d] 堆     [ d0001-d0002                ]        2 台     未配置测点            ⌄
```

- 栅格：`--lvcols: 186px minmax(0,1fr) 84px 226px 26px`（≤1100px 收窄为 `158 / 1fr / 74 / 168 / 24`）；
- 列标题 `.lv-thead` 只出现一次，每行不再重复"编码范围"这类标签，纵向空间全给输入框；
- 编码范围输入框 36px 高、等宽字体、宽度随栏位伸展（1440 下约 520px），是该行最宽元素；
- 点整行（`.lv-main`）展开测点编辑；`input` / `button` 上的点击不触发；
- 展开区顺序固定为「添加输入 + 快捷按钮 → 已配测点 N → chips」，避免 20+ 个 chip 把输入框顶出视野；
- 测点输入是**单行高度的 `textarea`**（`rows=1`，随内容长高，最高 104px 后内部滚动）：`<input>` 会把粘贴进来的换行压成空格，整列粘贴时无法可靠切分；
- 分隔符认**逗号 / 中文逗号 / 顿号 / 分号 / 空格 / 制表符 / 换行**，Excel 里复制一列 `v008…v021` 直接粘进来自动拆成多个测点；同名测点自动去重，解析失败的 token 在 toast 里点名；
- 已配测点行右侧有「清空」按钮（无测点时隐藏），点一次变「确认清空」、3 秒内再点才执行，避免误删一二十个 chip；
- 空态用灰色"未配置测点"，0 点层在规模估算里会被明确提示；
- 非法范围：输入框 `.lv-inp.bad` 红边 + 失焦 toast，输入过程中即时清除错误态；
- 每层给贴近真实取值的占位提示（`RANGE_HINT`），比统一示例更好填。

`PCS` 分组的「下级结构」开关不放在层级行里，而是提到列标题之上的 `#groupExtra`，虚线框 `inline-block` 贴合内容宽度。

## 4. 实时路径预览

默认折叠成一行（图标 + 标题 + 摘要 + 箭头），摘要形如「8 层 · 6,224 台设备 · 首条 root.cm.z01.yc.c101…」。展开后显示：

- 诊断表：每层范围是否可解析（无法解析标红、无测点标黄）、节点数、首尾路径样例；
- `path-sample` 代码块：真实拼接结果的样例路径，带 macOS 风格窗头。

这样设计的理由：预览是"核对工具"，不是主工作区。常驻展开会和表单抢宽度，也把内容顶出一屏。

## 5. 视觉规范

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#f4f6fb` | 页面底色（叠加两处低透明度径向渐变） |
| `--card` | `#ffffff` | 卡片 |
| `--ink` / `--ink2` / `--ink3` | `#0f172a` / `#55617a` / `#8d99ae` | 主 / 次 / 辅助文字 |
| `--line` / `--line2` | `#e8edf6` / `#dde4f0` | 描边 |
| `--brand` / `--brand2` | `#2563eb` / `#4f46e5` | 主色 / 渐变副色 |
| `--ok` / `--warn` | `#0b7a5f` / `#a55b06` | 成功 / 警告 |
| `--radius` | `16px` | 卡片圆角 |
| `--ease` | `cubic-bezier(.22,.61,.36,1)` | 统一缓动 |
| `--mono` | 系统等宽栈 | 路径、编码、数字 |

约定：

- 浅色、白底卡片、1px 冷灰描边、极轻阴影；不用大面积色块；
- 数字统一 `font-variant-numeric: tabular-nums`，避免跳动；
- 主按钮 `.btn.primary` 才用渐变，其余按钮白底描边；
- 图标一律内联 SVG（`stroke-width` 1.7–1.9，`stroke-linecap: round`），不引图标库。

## 6. 响应式断点

| 条件 | 行为 |
|---|---|
| `max-height: 860px` | 收紧内边距、隐藏卡片说明文字，层级行再收一档 |
| `max-height: 820px` | 收起页头摘要（`.hero`），把高度还给表单 |
| `max-height: 760px` | 再隐藏层级卡标题区，行内边距降到 5px |
| `max-width: 1100px` | 规模四格改两列；页头摘要换行；层级栅格收窄 |
| `max-width: 820px` | 放弃固定工作台，回整页滚动；层级行改三行堆叠（名称+设备数 / 输入 / 测点） |

1440×900 下面板可视 659px，四个页签均无整页滚动；1024×768 与 1280×720 同样无整页滚动。

## 7. 交互细节

- 页签用 `location.hash` 记忆，刷新后停留在原页签；
- 层级行 `role="button"` + `tabindex="0"` + `aria-expanded`，支持 Enter / Space 展开；
- 展开后自动聚焦"添加测点"输入框，并 `scrollIntoView({block:'nearest'})`，不打断阅读位置；
- 连接测试有"静默心跳"（`quiet=true`），只更新指示灯，不刷日志；
- 控制台日志按级别配色，自动滚底；用户手动上滚后不再强制跟随；
- 生成按钮与停止按钮互斥，运行中禁止重复提交。

## 8. 改动指引

| 想做什么 | 改哪里 |
|---|---|
| 加一个页签 | 顶栏 `.tab[data-tab]` + `<div class="panel" id="...">` + `activateTab()` 里的初始化 |
| 加一个 BMS 层级 | `config.yaml` 的 `groups.BMS` + `engine.py` 的 `node_counts` / `iter_devices`（五层是硬编码的嵌套） |
| 改层级行布局 | `.lv-card` 的 `--lvcols`，以及 `renderLevels()` 生成的 DOM 结构，两处必须同步 |
| 改配色 | `:root` 变量 |
| 调预览卡 | `.pv-card` / `.pv-hd` / `.pv-body`；折叠状态由 `#pvToggle` 控制 |
| 改控制台高度 | `--dockh`（展开 238px、折叠 42px），`.app` 的高度算式会自动跟随 |
